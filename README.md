奶龙跑酷游戏 - 项目说明
🎮 项目简介
本项目是一款3D卡通休闲闯关跑酷游戏。玩家操控卡通小人在多层地形关卡中跑酷闯关，躲避智能奶龙追击，利用二段跳跨越特殊地形，最终抵达终点完成通关。游戏画面清新、节奏轻快、玩法完整，适合课程设计、个人作品展示。
🕹️ 操作方式
•	WASD — 角色前后左右移动（带平滑加速/减速手感）
•	空格键 — 跳跃，支持二段跳
•	无鼠标视角 — 固定第三人称尾随视角，不穿模、不晃动
📌 核心功能亮点
1. 完整游戏首页系统
•	游戏启动优先进入开始界面
•	关卡选择：3个难度递增关卡（简单 / 普通 / 困难）
•	皮肤选择：默认小黄人皮肤 + 小黄人风格新款皮肤
•	首页自带 BGM开关 / 音效开关
2. 二段跳机制 & 专属地形
•	玩家支持空中二段跳，落地重置次数
•	地图内置仅二段跳可通过的高墙、宽沟地形
•	难度越高，二段跳专属障碍越多
3. 智能奶龙追击 AI（核心特色）
•	奶龙为原创高品质卡通3D模型，无橡皮泥质感
•	AI 支持自动寻路、预判地形、自动二段跳越障
•	跳跃动作平滑连贯，无闪现、无瞬移、无贴墙瞬跳
•	速度经过精细调节：不会轻易甩开、不会瞬间追上，拉扯手感极佳
•	抓到玩家触发：奶龙捧腹大笑3D动画
4. 终点通关系统
•	每关跑酷距离约 200米，设置醒目终点拱门
•	抵达终点后自动停止追击
•	玩家触发欢呼跳舞通关动画
•	终点播放鲜花、彩屑庆祝粒子特效，BGM自动切换高潮版本
5. 完整音频系统
•	全局欢快卡通循环背景音乐
•	通关高潮BGM、失败搞笑音效
•	失败触发奶龙笑声专属音效
•	支持独立开关背景音乐、音效
🗺️ 三难度关卡设计
•	关卡1（简单）：障碍稀疏、高低差少、容错高，适合新手熟悉操作
•	关卡2（普通）：增加平台、弯道、连续跳跃，加入少量二段跳地形
•	关卡3（困难）：窄平台、密集断层、大量二段跳专属障碍，节奏紧凑挑战性高
🧩 版本迭代记录
•	版本A：基础跑酷、奶龙追击、基础地图机制
•	版本B：优化奶龙AI，新增奶龙二段跳、地形预判、无闪现移动
•	版本C：新增首页、选关、皮肤系统、200米终点、通关动画、鲜花粒子、全套BGM音效系统
